# Photo → Pantry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the MVP photo-capture pipeline — camera/picker → compressed
upload → Gemini 3.6 Flash (Interactions API) via a locked-down Edge Function →
local confirmation sheet → flag-gated write to Supabase `inventory`.

**Architecture:** Pure detection/matching/wire-format logic lives under
`src/lib/photo/` so it is testable in plain Node via vitest; the Deno Edge
Function imports those same files by relative path instead of duplicating
them. Supabase is the single source of truth for pantry state — no separate
durable local store. A compile-time flag gates the `inventory` write so
detection can ship and be exercised before the write path is trusted.

**Tech Stack:** Expo Router, React Native, TanStack Query, Supabase (Postgres
+ Auth + Edge Functions), Zod, Deno (Edge Function runtime), Gemini 3.6 Flash
via the Interactions API.

**Governing spec:** `docs/specs/2026-08-07-photo-to-pantry-design.md`

## Global Constraints

- TypeScript `strict: true`. No `any` — use `unknown` at boundaries and narrow (`docs/02_STYLE_GUIDE.md`).
- Named exports only, except expo-router route files (`app/**`), which must default-export.
- No hardcoded colors or spacing — use `src/theme/tokens.ts` exclusively.
- Accessibility props (`accessible`, `accessibilityRole`, `accessibilityLabel`, and `accessibilityHint` where the action isn't self-evident) are required on every interactive element — CI enforces this.
- `src/engine/` stays pure — nothing in this plan touches it.
- Model string is exactly `gemini-3.6-flash`, never `gemini-flash-latest` (`docs/01_TECHNICAL_SPEC.md` §2.4).
- Third-party API keys (`GEMINI_API_KEY`) live only in Supabase secrets, read only inside the Edge Function via `Deno.env.get()`. Never in `EXPO_PUBLIC_*`, never echoed into a log line or error response (`docs/06_API_KEYS_AND_ENV.md`).
- No `service_role` key anywhere in this plan — every server-side Supabase call uses the caller's own JWT.
- Every new/changed table has RLS enabled in the same migration that touches it. Any function called via `supabase.rpc()` must live in the `public` schema — `private` is excluded from `api.schemas` and is unreachable over PostgREST regardless of grants (confirmed by `supabase/migrations/0002_grant_membership_helper.sql`'s own comment).
- Commits: imperative, under 50 chars (`docs/02_STYLE_GUIDE.md`).
- `supabase/functions/**` is Deno runtime, not Node — already excluded from `tsconfig.json` and `eslint.config.mjs`. Files there are checked by the Supabase CLI, not `tsc`/`eslint`, and are verified manually via `supabase functions serve`, never by vitest.
- Within `src/lib/photo/`, cross-module imports use relative paths (`./schema`, not `@/lib/photo/schema`) so the same files import cleanly from Deno via a relative path from `supabase/functions/`. Only *external* consumers (components, hooks) use the `@/` alias.
- Anything that imports `@/lib/supabase` transitively imports `src/lib/storage.ts`, which calls `react-native-mmkv` + `expo-secure-store` at module top level — both throw under plain Node/vitest (no native runtime). Any test that needs the Supabase client must use `vi.mock('@/lib/supabase', ...)`, never a real or dynamic import of it.

```ts
export interface Dimensions {
  width: number;
  height: number;
}

const MAX_DIMENSION = 640;

/**
 * Scales the longer edge down to 640px, preserving aspect ratio -- the model
 * input size (docs/01_TECHNICAL_SPEC.md §5.1). Never upscales.
 */
export function resizeTarget(source: Dimensions): Dimensions {
  const longest = Math.max(source.width, source.height);
  if (longest <= MAX_DIMENSION || longest <= 0) {
    return { width: Math.round(source.width), height: Math.round(source.height) };
  }
  const scale = MAX_DIMENSION / longest;
  return {
    width: Math.round(source.width * scale),
    height: Math.round(source.height * scale),
  };
}
```

```ts
// src/lib/photo/schema.ts
import { z } from 'zod';

export const DETECTED_ITEM_UNITS = ['grams', 'milliliters', 'pieces', 'cups', 'unknown'] as const;

export const detectedItemSchema = z.object({
  name: z.string().min(1),
  quantity: z.number(),
  unit: z.enum(DETECTED_ITEM_UNITS),
  confidence: z.number().min(0).max(1),
});

export const detectedItemsSchema = z.array(detectedItemSchema);

export type DetectedItem = z.infer<typeof detectedItemSchema>;

/**
 * OpenAPI 3.0 subset the Interactions API accepts as response_format[0].schema.
 * Field names and constraints mirror detectedItemSchema exactly --
 * docs/01_TECHNICAL_SPEC.md §2.4.
 */
export const GEMINI_INGREDIENT_SCHEMA = {
  type: 'array',
  items: {
    type: 'object',
    properties: {
      name: { type: 'string', description: 'Generic ingredient type, never a brand' },
      quantity: { type: 'number' },
      unit: { type: 'string', enum: [...DETECTED_ITEM_UNITS] },
      confidence: { type: 'number', description: '0.0 to 1.0' },
    },
    required: ['name', 'quantity', 'unit', 'confidence'],
  },
} as const;

/** ~1.5MB decoded, matching the design's per-image payload cap. */
const MAX_IMAGE_BYTES = 1.5 * 1024 * 1024;

function approxBase64DecodedBytes(base64: string): number {
  return Math.floor((base64.length * 3) / 4);
}

/**
 * Validated on the Edge Function before any Gemini call, so an oversized or
 * malformed request costs nothing -- docs/specs/2026-08-07-photo-to-pantry-design.md
 * Decision 6.
 */
export const analyzeRequestSchema = z.object({
  images: z
    .array(
      z.object({
        data: z
          .string()
          .min(1)
          .refine((data) => approxBase64DecodedBytes(data) <= MAX_IMAGE_BYTES, {
            message: 'Image exceeds 1.5MB after decoding',
          }),
        mimeType: z.literal('image/jpeg'),
      })
    )
    .min(1, 'At least one image is required')
    .max(10, 'At most 10 images per request'),
});

export type AnalyzeRequest = z.infer<typeof analyzeRequestSchema>;
```

```ts
// src/lib/photo/normalize.ts

/**
 * Minimal structural subset of @/data/catalog's VocabularyEntry. Defined
 * locally (not imported) so this file has zero `@/` alias dependencies and
 * stays safe to import from Deno via a relative path -- see Global
 * Constraints. The real, richer VocabularyEntry is structurally assignable
 * to this, so callers pass it straight through with no adapter.
 */
export interface VocabularyEntry {
  id: string;
  displayName: string;
}

export interface NormalizeResult {
  matched: { id: string; displayName: string } | null;
  raw: string;
}

/**
 * Small hand-maintained table for known synonyms the bundled vocabulary does
 * not itself link -- ingredients.json has no synonym field, it's derived
 * mechanically from TheMealDB. This is deliberately NOT general fuzzy
 * matching: "scallion" and "green onion" share no characters, so no
 * string-similarity approach would catch them. docs/01_TECHNICAL_SPEC.md
 * §5.1 names this exact case as the acceptance test.
 */
const SYNONYMS: Record<string, string> = {
  scallion: 'green_onion',
  scallions: 'green_onion',
  'spring onion': 'green_onion',
  'spring onions': 'green_onion',
};

function slugify(text: string): string {
  return text
    .toLowerCase()
    .trim()
    .replace(/[^a-z0-9\s_-]/g, '')
    .replace(/[\s-]+/g, '_');
}

function normalizeSpaces(text: string): string {
  return text.toLowerCase().trim().replace(/\s+/g, ' ');
}

export interface IngredientMatcher {
  normalize(rawName: string): NormalizeResult;
}

/**
 * Maps a free-text ingredient name (as returned by the vision model) to a
 * canonical id from the bundled vocabulary: exact id, then exact display
 * name, then the synonym table above. Anything else is unmatched --
 * inventing a new id here would create a permanent duplicate in the shared
 * vocabulary, which is worse than surfacing it to the user.
 */
export function createIngredientMatcher(vocabulary: readonly VocabularyEntry[]): IngredientMatcher {
  const bySlug = new Map(vocabulary.map((entry) => [entry.id, entry]));
  const byDisplayName = new Map(vocabulary.map((entry) => [normalizeSpaces(entry.displayName), entry]));

  return {
    normalize(rawName: string): NormalizeResult {
      const direct = bySlug.get(slugify(rawName)) ?? byDisplayName.get(normalizeSpaces(rawName));
      if (direct !== undefined) {
        return { matched: { id: direct.id, displayName: direct.displayName }, raw: rawName };
      }

      const synonymId = SYNONYMS[normalizeSpaces(rawName)];
      const synonymEntry = synonymId !== undefined ? bySlug.get(synonymId) : undefined;
      if (synonymEntry !== undefined) {
        return { matched: { id: synonymEntry.id, displayName: synonymEntry.displayName }, raw: rawName };
      }

      return { matched: null, raw: rawName };
    },
  };
}
```

```ts
/**
 * Exact match only -- a naive `includes()`/`startsWith()` check is how
 * "evil-homechef.app" or "homechef.app.evil.com" slips past a suffix/prefix
 * comparison. A missing Origin header (native apps never send one) passes
 * through here; the JWT check is what actually gates a native caller --
 * docs/specs/2026-08-07-photo-to-pantry-design.md Decision 5.
 */
export function isAllowedOrigin(origin: string | null, allowlist: readonly string[]): boolean {
  if (origin === null) return true;
  return allowlist.includes(origin);
}
```

```ts
// src/lib/photo/gemini-response.ts

export interface InteractionsStep {
  type: string;
  content?: Array<{ type: string; text?: string }>;
}

export interface InteractionsResponseBody {
  status: string;
  steps?: InteractionsStep[];
}

export type ExtractResult =
  | { ok: true; json: unknown }
  | { ok: false; reason: 'not_completed' | 'no_model_output' | 'not_text' | 'invalid_json' };

/**
 * Interactions API responses wrap output in a `steps` timeline rather than
 * the older `candidates[0].content.parts[0].text` shape. We search for the
 * `model_output` step rather than assume a fixed index, since a `thought`
 * step may or may not precede it.
 */
export function extractStructuredOutput(response: InteractionsResponseBody): ExtractResult {
  if (response.status !== 'completed') {
    return { ok: false, reason: 'not_completed' };
  }

  const modelOutput = (response.steps ?? []).find((step) => step.type === 'model_output');
  if (modelOutput === undefined) {
    return { ok: false, reason: 'no_model_output' };
  }

  const textContent = (modelOutput.content ?? []).find((item) => item.type === 'text');
  if (textContent?.text === undefined) {
    return { ok: false, reason: 'not_text' };
  }

  try {
    return { ok: true, json: JSON.parse(textContent.text) };
  } catch {
    return { ok: false, reason: 'invalid_json' };
  }
}
```

```ts
export interface UpsertInventoryItem {

export async function upsertInventoryItems(

  items: readonly UpsertInventoryItem[]

      added_by: item.addedBy ?? null,

  );
```

```sql
-- supabase/migrations/0004_photo_scan_quota.sql
-- ---------------------------------------------------------------------------
-- photo_scan_quota: per-user daily cap on Gemini Vision calls.
--
-- docs/specs/2026-08-07-photo-to-pantry-design.md Decision 4/5.
-- The analyze-pantry-photo Edge Function calls consume_photo_scan_quota() via
-- supabase.rpc(), using the CALLER's own JWT -- never service_role. That is
-- only possible if this function lives in `public`: `private` is deliberately
-- excluded from api.schemas (0002_grant_membership_helper.sql), so a function
-- there is unreachable over PostgREST no matter what is granted.
--
-- SECURITY DEFINER is still required even in `public`: the table has no
-- client-facing INSERT/UPDATE policy at all, so the only way scan_count can
-- change is through this function's own body, which increments atomically
-- and resets on a new calendar day.
-- ---------------------------------------------------------------------------

create table photo_scan_quota (
  user_id     uuid primary key references profiles(id) on delete cascade,
  scan_date   date not null default current_date,
  scan_count  int not null default 0,
  updated_at  timestamptz not null default now()
);

alter table photo_scan_quota enable row level security;

-- No insert/update/delete policy for clients -- every write goes through
-- consume_photo_scan_quota(), which is the only place the increment and the
-- daily reset can happen atomically.
create policy photo_scan_quota_own_read on photo_scan_quota
  for select to authenticated
  using (user_id = (select auth.uid()));

create or replace function public.consume_photo_scan_quota(max_per_day int)
returns boolean
language plpgsql
security definer
set search_path = ''
as $$
declare
  caller uuid := (select auth.uid());
  today_count int;
begin
  if caller is null then
    return false;
  end if;

  insert into public.photo_scan_quota (user_id, scan_date, scan_count)
  values (caller, current_date, 0)
  on conflict (user_id) do update
    set scan_date = current_date,
        scan_count = case
          when public.photo_scan_quota.scan_date = current_date
          then public.photo_scan_quota.scan_count
          else 0
        end
  returning scan_count into today_count;

  if today_count >= max_per_day then
    return false;
  end if;

  update public.photo_scan_quota
     set scan_count = scan_count + 1,
         updated_at = now()
   where user_id = caller;

  return true;
end;
$$;

revoke execute on function public.consume_photo_scan_quota(int) from public, anon;
grant execute on function public.consume_photo_scan_quota(int) to authenticated;
```

```ts
import { isAllowedOrigin } from '../../../src/lib/photo/origin.ts';

const ALLOWED_ORIGINS = (Deno.env.get('ALLOWED_ORIGINS') ?? '')
  .split(',')
  .map((origin) => origin.trim())
  .filter((origin) => origin.length > 0);

/**
 * Never `*` -- an exact-match allowlist, echoed back only when it matches, so
 * a browser on another origin never sees a permissive header at all.
 * docs/specs/2026-08-07-photo-to-pantry-design.md Decision 5.
 */
export function corsHeaders(origin: string | null): HeadersInit {
  const headers: Record<string, string> = {
    'Access-Control-Allow-Methods': 'POST, OPTIONS',
    'Access-Control-Allow-Headers': 'authorization, content-type, apikey',
    Vary: 'Origin',
  };
  if (origin !== null && ALLOWED_ORIGINS.includes(origin)) {
    headers['Access-Control-Allow-Origin'] = origin;
  }
  return headers;
}

export function isOriginAllowed(origin: string | null): boolean {
  return isAllowedOrigin(origin, ALLOWED_ORIGINS);
}
```

```ts
// supabase/functions/_shared/gemini.ts
import { buildInteractionsRequest, type GeminiImageInput } from '../../../src/lib/photo/gemini-request.ts';
import { extractStructuredOutput } from '../../../src/lib/photo/gemini-response.ts';

const INTERACTIONS_URL = 'https://generativelanguage.googleapis.com/v1beta/interactions';

export class GeminiCallError extends Error {}

/**
 * Wire format verified against ai.google.dev/gemini-api/docs (Interactions
 * API, Aug 2026) -- see
 * docs/specs/2026-08-07-photo-to-pantry-design.md Decision 10.
 * This is the ONLY file where that shape appears; a future correction stays
 * contained here.
 */
export async function detectIngredients(
  images: readonly GeminiImageInput[],
  apiKey: string
): Promise<unknown> {
  const res = await fetch(INTERACTIONS_URL, {
    method: 'POST',
    headers: {
      'x-goog-api-key': apiKey,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify(buildInteractionsRequest(images)),
  });

  if (!res.ok) {
    // Never echo the key or the raw response body -- docs/06_API_KEYS_AND_ENV.md.
    throw new GeminiCallError(`Gemini call failed with status ${res.status}`);
  }

  const parsed = extractStructuredOutput(await res.json());
  if (!parsed.ok) {
    throw new GeminiCallError(`Could not extract structured output: ${parsed.reason}`);
  }

  return parsed.json;
}
```

```ts
// supabase/functions/analyze-pantry-photo/index.ts
import { createClient } from 'npm:@supabase/supabase-js@2';
import { corsHeaders, isOriginAllowed } from '../_shared/cors.ts';
import { detectIngredients, GeminiCallError } from '../_shared/gemini.ts';
import { analyzeRequestSchema, detectedItemsSchema } from '../../../src/lib/photo/schema.ts';
import { createIngredientMatcher, type VocabularyEntry } from '../../../src/lib/photo/normalize.ts';
import vocabulary from '../_shared/ingredients.generated.json' with { type: 'json' };

const DAILY_PHOTO_SCANS = 20;

const matcher = createIngredientMatcher(vocabulary as VocabularyEntry[]);

function jsonResponse(body: unknown, status: number, origin: string | null): Response {
  return new Response(JSON.stringify(body), {
    status,
    headers: { ...corsHeaders(origin), 'Content-Type': 'application/json' },
  });
}

Deno.serve(async (req: Request) => {
  const origin = req.headers.get('Origin');

  if (req.method === 'OPTIONS') {
    return new Response('ok', { headers: corsHeaders(origin) });
  }

  if (!isOriginAllowed(origin)) {
    return jsonResponse({ error: 'Forbidden' }, 403, origin);
  }

  const authHeader = req.headers.get('Authorization');
  if (authHeader === null) {
    return jsonResponse({ error: 'Unauthorized' }, 401, origin);
  }

  const supabaseUrl = Deno.env.get('SUPABASE_URL');
  const supabaseAnonKey = Deno.env.get('SUPABASE_ANON_KEY');
  if (supabaseUrl === undefined || supabaseAnonKey === undefined) {
    console.error('SUPABASE_URL or SUPABASE_ANON_KEY not configured');
    return jsonResponse({ error: 'Service unavailable' }, 503, origin);
  }

  // Scoped to the caller's own JWT -- auth.uid() inside the quota function
  // resolves to the real caller, never a service-role bypass.
  const supabase = createClient(supabaseUrl, supabaseAnonKey, {
    global: { headers: { Authorization: authHeader } },
  });

  const { data: userData, error: userError } = await supabase.auth.getUser();
  if (userError || userData.user === null) {
    return jsonResponse({ error: 'Unauthorized' }, 401, origin);
  }

  let body: unknown;
  try {
    body = await req.json();
  } catch {
    return jsonResponse({ error: 'Invalid JSON body' }, 400, origin);
  }

  const parsedRequest = analyzeRequestSchema.safeParse(body);
  if (!parsedRequest.success) {
    return jsonResponse({ error: 'Invalid request' }, 400, origin);
  }

  const { data: allowed, error: quotaError } = await supabase.rpc('consume_photo_scan_quota', {
    max_per_day: DAILY_PHOTO_SCANS,
  });
  if (quotaError) {
    console.error('Quota check failed:', quotaError.message);
    return jsonResponse({ error: 'Service unavailable' }, 503, origin);
  }
  if (allowed !== true) {
    return jsonResponse({ error: 'Daily photo scan limit reached' }, 429, origin);
  }

  const geminiApiKey = Deno.env.get('GEMINI_API_KEY');
  if (geminiApiKey === undefined) {
    console.error('GEMINI_API_KEY not configured');
    return jsonResponse({ error: 'Service unavailable' }, 503, origin);
  }

  let rawDetections: unknown;
  try {
    rawDetections = await detectIngredients(
      parsedRequest.data.images.map((image) => ({ base64Data: image.data, mimeType: image.mimeType })),
      geminiApiKey
    );
  } catch (err) {
    console.error('Gemini call failed:', err instanceof GeminiCallError ? err.message : 'unknown error');
    return jsonResponse({ error: "Couldn't read that photo, try again or add manually" }, 502, origin);
  }

  const parsedDetections = detectedItemsSchema.safeParse(rawDetections);
  if (!parsedDetections.success) {
    console.error('Gemini response failed schema validation');
    return jsonResponse({ error: "Couldn't read that photo, try again or add manually" }, 502, origin);
  }

  const items: Array<{ id: string; displayName: string; quantity: number; unit: string; confidence: number }> = [];
  const unmatched: string[] = [];

  for (const item of parsedDetections.data) {
    const result = matcher.normalize(item.name);
    if (result.matched === null) {
      unmatched.push(item.name);
      continue;
    }
    items.push({
      id: result.matched.id,
      displayName: result.matched.displayName,
      quantity: item.quantity,
      unit: item.unit,
      confidence: item.confidence,
    });
  }

  return jsonResponse({ items, unmatched }, 200, origin);
});
```

```ts
// src/lib/auth/session.ts
import { supabase } from '@/lib/supabase';

/**
 * The Edge Function's JWT check and inventory's RLS policies both need a
 * real Supabase session. Anonymous sign-in is the minimum that satisfies
 * both without building real auth screens.
 * docs/specs/2026-08-07-photo-to-pantry-design.md Decision 3.
 */
export async function ensureAnonymousSession(): Promise<string> {
  const { data: existing, error: getError } = await supabase.auth.getSession();
  if (getError) throw getError;
  if (existing.session !== null) return existing.session.user.id;

  const { data, error } = await supabase.auth.signInAnonymously();
  if (error) throw error;
  if (data.session === null) throw new Error('Anonymous sign-in returned no session');
  return data.session.user.id;
}
```

```ts
// src/lib/photo/compress.ts
import * as ImageManipulator from 'expo-image-manipulator';
import { resizeTarget } from '@/lib/photo/resize-target';

export interface CompressedImage {
  base64Data: string;
  mimeType: 'image/jpeg';
}

/**
 * Resizes to <=640px on the long edge and JPEG-encodes at ~0.7 quality
 * before upload -- docs/01_TECHNICAL_SPEC.md §5.1. Runs on-device so a
 * 12MP photo never leaves the phone.
 */
export async function compressForUpload(
  uri: string,
  source: { width: number; height: number }
): Promise<CompressedImage> {
  const target = resizeTarget(source);

  const result = await ImageManipulator.manipulateAsync(
    uri,
    [{ resize: { width: target.width, height: target.height } }],
    { compress: 0.7, format: ImageManipulator.SaveFormat.JPEG, base64: true }
  );

  if (result.base64 === undefined) {
    throw new Error('Image manipulation did not return base64 data');
  }

  return { base64Data: result.base64, mimeType: 'image/jpeg' };
}
```

```tsx
// src/components/DetectionConfirmSheet.tsx
import { useState } from 'react';
import { Pressable, ScrollView, StyleSheet, Text, View, useColorScheme } from 'react-native';

import { IngredientChip } from '@/components/IngredientChip';
import type { AnalyzedItem } from '@/lib/photo/analyze';
import type { ConfirmedPantryItem } from '@/lib/photo/confirm-items';
import { palette, radius, space, touchTarget, type as typeScale } from '@/theme/tokens';

const LOW_CONFIDENCE_THRESHOLD = 0.7;

export interface DetectionConfirmSheetProps {
  items: readonly AnalyzedItem[];
  unmatched: readonly string[];
  onConfirm: (items: readonly ConfirmedPantryItem[]) => void;
  onCancel: () => void;
}

/**
 * Nothing here is written until the user taps Confirm -- this is the
 * defense against a bad vision-model read poisoning the shared pantry.
 * docs/01_TECHNICAL_SPEC.md §5.1.
 */
export function DetectionConfirmSheet({ items, unmatched, onConfirm, onCancel }: DetectionConfirmSheetProps) {
  const theme = palette[useColorScheme() === 'dark' ? 'dark' : 'light'];
  const styles = createStyles(theme);
  const [removedIds, setRemovedIds] = useState<Set<string>>(new Set());

  const keptItems = items.filter((item) => !removedIds.has(item.id));

  function removeItem(id: string) {
    setRemovedIds((current) => new Set(current).add(id));
  }

  function confirm() {
    onConfirm(keptItems.map((item) => ({ ingredientId: item.id, quantity: item.quantity, unit: item.unit })));
  }

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Confirm what we found</Text>
      <ScrollView contentContainerStyle={styles.chipList}>
        {items
          .filter((item) => !removedIds.has(item.id))
          .map((item) => (
            <View key={item.id} style={styles.row}>
              <IngredientChip
                id={item.id}
                label={item.displayName}
                measure={`${item.quantity} ${item.unit}`}
                variant={item.confidence < LOW_CONFIDENCE_THRESHOLD ? 'missing' : 'pantry'}
                onRemove={removeItem}
              />
              {item.confidence < LOW_CONFIDENCE_THRESHOLD ? (
```

```tsx
// src/components/PhotoCapture.tsx
import { useState } from 'react';
import { Pressable, StyleSheet, Text, View, useColorScheme } from 'react-native';
import * as ImagePicker from 'expo-image-picker';

import { isSupabaseConfigured } from '@/lib/env';
import { compressForUpload, type CompressedImage } from '@/lib/photo/compress';
import { useAnalyzePantryPhotos, useConfirmPantryPhotoItems } from '@/hooks/usePantryPhoto';
import { DetectionConfirmSheet } from '@/components/DetectionConfirmSheet';
import { palette, radius, space, touchTarget, type as typeScale } from '@/theme/tokens';

const MAX_IMAGES = 10;

export interface PhotoCaptureProps {
  householdId: string | undefined;
  onDone: () => void;
}

export function PhotoCapture({ householdId, onDone }: PhotoCaptureProps) {
  const theme = palette[useColorScheme() === 'dark' ? 'dark' : 'light'];
  const styles = createStyles(theme);
  const [images, setImages] = useState<CompressedImage[]>([]);
  const analyze = useAnalyzePantryPhotos();
  const confirm = useConfirmPantryPhotoItems(householdId);

  async function captureOne() {
    const result = await ImagePicker.launchCameraAsync({ quality: 1, base64: false });
    if (result.canceled) return;
    const asset = result.assets[0];
    if (asset === undefined || images.length >= MAX_IMAGES) return;
    const compressed = await compressForUpload(asset.uri, { width: asset.width, height: asset.height });
    setImages((current) => [...current, compressed]);
  }

  async function pickFromLibrary() {
    const result = await ImagePicker.launchImageLibraryAsync({
      allowsMultipleSelection: true,
      selectionLimit: MAX_IMAGES - images.length,
      quality: 1,
    });
    if (result.canceled) return;
    const compressedAssets = await Promise.all(
      result.assets.map((asset) => compressForUpload(asset.uri, { width: asset.width, height: asset.height }))
    );
    setImages((current) => [...current, ...compressedAssets].slice(0, MAX_IMAGES));
  }

  if (!isSupabaseConfigured) {
    return (
      <View style={styles.container}>
        <Text style={styles.disabledText}>Photo capture needs Supabase configured (see .env.example).</Text>
      </View>
    );
  }

  if (analyze.data !== undefined) {
    return (
      <DetectionConfirmSheet
        items={analyze.data.items}
        unmatched={analyze.data.unmatched}
        onCancel={onDone}
        onConfirm={(confirmedItems) => confirm.mutate(confirmedItems, { onSuccess: onDone })}
      />
    );
  }

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Capture pantry inventory</Text>
      <Text style={styles.caption}>{images.length} of {MAX_IMAGES} photos</Text>
      <View style={styles.actions}>
        <Pressable
          accessible
          accessibilityRole="button"
          accessibilityLabel="Take a photo"
          accessibilityHint="Opens the camera to capture a fridge or pantry shelf"
          onPress={captureOne}
          disabled={images.length >= MAX_IMAGES}
          style={[styles.button, styles.buttonPrimary]}
        >
          <Text style={styles.buttonTextPrimary}>Take a photo</Text>
        </Pressable>
        <Pressable
          accessible
          accessibilityRole="button"
          accessibilityLabel="Choose from library"
          accessibilityHint="Picks existing photos of your fridge or pantry"
          onPress={pickFromLibrary}
          disabled={images.length >= MAX_IMAGES}
          style={[styles.button, styles.buttonSecondary]}
        >
          <Text style={styles.buttonTextSecondary}>Choose from library</Text>
        </Pressable>
      </View>
      <Pressable
        accessible
        accessibilityRole="button"
        accessibilityLabel={`Analyze ${images.length} photos`}
        accessibilityHint="Sends the captured photos to detect ingredients"
        onPress={() => analyze.mutate(images)}
        disabled={images.length === 0 || analyze.isPending}
        style={[styles.button, styles.buttonPrimary]}
      >
        <Text style={styles.buttonTextPrimary}>{analyze.isPending ? 'Analyzing...' : 'Analyze photos'}</Text>
      </Pressable>
      {analyze.isError ? (
        <Text style={styles.errorText}>Couldn't read those photos, try again or add manually.</Text>
      ) : null}
    </View>
  );
}

function createStyles(theme: (typeof palette)['light']) {
  return StyleSheet.create({
    container: { gap: space.md, padding: space.lg, backgroundColor: theme.bg },
    title: { ...typeScale.title, color: theme.text },
    caption: { ...typeScale.caption, color: theme.textMuted },
    disabledText: { ...typeScale.body, color: theme.textMuted },
    errorText: { ...typeScale.body, color: theme.danger },
    actions: { flexDirection: 'row', gap: space.sm },
    button: {
      flex: 1,
      minHeight: touchTarget.primaryCtaHeight,
      borderRadius: radius.md,
      alignItems: 'center',
      justifyContent: 'center',
    },
    buttonPrimary: { backgroundColor: theme.accent },
    buttonSecondary: { backgroundColor: theme.surfaceAlt, borderWidth: 1, borderColor: theme.border },
    buttonTextPrimary: { ...typeScale.bodyStrong, color: theme.accentText },
    buttonTextSecondary: { ...typeScale.bodyStrong, color: theme.text },
  });
}
```

  pure logic under `supabase/functions/_shared/`. This plan places it under
  `src/lib/photo/` instead, with the Deno function importing it by relative

  available in this environment, so pure functions placed there would be
  untestable. Placing them in `src/lib/photo/` makes every pure module
  vitest-testable while Deno still reaches them via a relative import — same
  design intent ("pure, no Deno globals, testable"), better-fitting location.
